# List of AUTHORS who contributed over time to the mod-item-enchant-system project

## Point of current development

The project is currently developed at [https://github.com/Opertol900/mod-item-enchant-system](https://github.com/Opertol900/mod-item-enchant-system) as a module for [AzerothCore](https://www.azerothcore.org/).

## History of development

`mod-item-enchant-system` was created in 2026 as an independent, server-side item enhancement module for AzerothCore 3.3.5a. The project implements Lineage II-style item enchanting while using AzerothCore's native module architecture and standard World of Warcraft interfaces.

The current source code and development history are maintained at:

[https://github.com/Opertol900/mod-item-enchant-system](https://github.com/Opertol900/mod-item-enchant-system)
